# Infraestructura

Archivos de configuracion para despliegue, contenedores y servicios externos.

## Estado actual

El `docker-compose.yml` oficial del entorno de desarrollo esta en la raiz del proyecto.

Esta carpeta queda reservada para configuraciones de infraestructura que no pertenecen directamente al codigo del backend o frontend, por ejemplo:

- configuracion de Nginx
- archivos de despliegue
- certificados de entorno local
- configuraciones futuras para produccion
